# Design Context

This file is the design context for the website (`site/`). The native app's
design system is `DESIGN.md`.

### Users

Windows developers evaluating terminal emulators and forks. They arrive skeptical of SmartScreen warnings, unsigned installers, and overclaimed parity. They need a fast read on what ships today, how to install, and whether the project is credible.

### Brand Personality

**Native · credible · precise**

### Aesthetic Direction

**The page is chrome; the terminal is the content.** Vercel and t3.codes set the bar: one framed column with hairline rails, the shadcn zinc scale in plain CSS, flat surfaces, no shadows on page elements, no gradients. All page chrome is neutral; the only color on the site is inside terminal windows (prompt, git output, the active-tab and focused-pane accent), so the product's content is what stands out. Light and dark follow the visitor's system until they pick one, and terminal windows and app captures switch with them. Anti-references: night-sky or glow heroes, purple gradients, gradient text, identical icon-and-heading card grids, kickers above headings, thick side-stripe callouts.

### Typography

| Role | Stack |
|------|--------|
| Display and body | Geist (self-hosted, weights 400 to 600), then Segoe UI Variable, system-ui |
| Commands, keys in code, terminals | JetBrains Mono (self-hosted; Ghostty's default terminal face) |
| Key chips | Geist 500 at 12px in a `kbd` chip |

Headlines are Geist 500 with -0.035em tracking; body is Geist 400 at 16px.

### Voice

Plain and specific: concrete nouns (PowerShell, WSL, `%LOCALAPPDATA%`, Ctrl+Shift+P), short sentences, sentence-case headings. A little wit is allowed in the first sentence of a section ("Survives Patch Tuesday.", "Built on Ghostty. Not by Ghostty."), never in a claim. Feature names stay plain.

### Design Principles

1. **Color belongs to the terminal**: chrome stays zinc; color appears only in terminal output and the app's own accent.
2. **Prove, then claim**: the hero demo uses real palette titles and default keys (pinned by `site/tests/terminal.test.mjs`), and each feature sits beside a real capture of the app.
3. **Copy is defensible**: every claim must pass `scripts/check-site-copy.ps1` and match the docs it cites.
4. **One moving thing**: only the hero demo animates; it pauses off-screen and shows still frames under `prefers-reduced-motion`.
5. **Conversion is obvious**: Download latest (primary), WinGet (default), Scoop (alternate), GitHub (tertiary).
